# Interview Experiences Sharing Platform

A Flask web app where users share and browse interview experiences.

## Features
- User accounts (login/register)
- Share experiences with company, role, difficulty rating
- Search and filter experiences
- Edit/delete your posts

## Setup
1. Clone repo
2. Install requirements: `pip install -r requirements.txt`
3. Run: `python app.py`

## Tech
- Python/Flask backend
- SQLite database
- Bootstrap frontend
